# Contribuindo para o FinanceApp

Obrigada por considerar contribuir com o FinanceApp! 🎉

## Como Contribuir

### 🐛 Reportar Bugs

Se encontrar um bug, abra uma [issue](https://github.com/Flavinha-Souza/FinanceApp/issues) incluindo:
- Descrição clara do problema
- Passos para reproduzir
- Comportamento esperado vs. atual
- Screenshots (se aplicável)
- Versão do app e dispositivo usado

### 💡 Sugerir Melhorias

Para sugerir novas funcionalidades:
- Abra uma issue com a tag `enhancement`
- Descreva a funcionalidade e sua utilidade
- Explique como ela se encaixaria no app

### 🔧 Enviar Pull Requests

1. **Fork** o repositório
2. **Clone** seu fork: `git clone https://github.com/Flavinha-Souza/FinanceApp.git`
3. **Crie uma branch**: `git checkout -b feature/minha-feature`
4. **Faça suas alterações** seguindo os padrões do projeto
5. **Commit**: `git commit -m 'Adiciona nova funcionalidade X'`
6. **Push**: `git push origin feature/minha-feature`
7. **Abra um Pull Request** descrevendo suas mudanças

## 📝 Padrões de Código

- Use nomes descritivos para variáveis e funções
- Mantenha a consistência com o código existente
- Comente código complexo quando necessário
- Evite código duplicado

## 🧪 Testes

Antes de enviar seu PR:
- Teste o app no Android e/ou iOS
- Verifique se não há erros no console
- Confirme que todas as funcionalidades existentes continuam funcionando

## 📋 Checklist do Pull Request

- [ ] O código segue os padrões do projeto
- [ ] Testei as alterações em dispositivo/emulador
- [ ] Atualizei a documentação (se necessário)
- [ ] Não há conflitos com a branch main

## 💬 Dúvidas?

Sinta-se à vontade para abrir uma issue com suas dúvidas!
